# 屏幕空间流体渲染场景——Agent能力测试

## 测试环境

**任务目标：**流体仿真一般用粒子模拟，所以这种场景的流体渲染一般就是在屏幕空间渲染出粒子的深度图，对深度图做一些平滑，然后再根据流体的材质属性计算反射折射等光照信息最终完成渲染。我给Agent设计的框架是，在一个基于WebGPU的流体仿真与渲染的项目中，扣掉项目中的渲染部分，在prompt中描述清楚流体渲染需要用到的算法以及需要注意的性能优化点，考察Agent任务完成情况。

**prompt：**

```
当前项目是一个WebGPU的流体仿真项目，使用的是粒子的仿真方式，但是渲染部分还很粗糙，用的是最简单的shading渲染每个粒子小球，你帮我参考NarrowRangeFilter.pdf这篇论文（论文就在项目目录下），实现一个更好的流体渲染结果：
1. 参考论文中的深度图滤波方式，平滑粒子小球的深度图。
2. 在screen-space完成流体渲染，你需要考虑流体的折射和反射，需要去查环境光贴图。
3. 将当前的小球渲染改成更高效的渲染方式，使用billboard渲染屏幕空间的粒子，可以接受投影误差，将球形粒子的透视投影近似成屏幕空间的圆形。
```

**结果：**

| 模型              | 完成时间 | 深度滤波                 | Billboard    | 屏幕空间流体 | 流体厚度 | 总评           |
| ----------------- | -------- | ------------------------ | ------------ | ------------ | -------- | -------------- |
| Opus 5            | 1小时    | 论文语义完整             | 4 顶点 strip | 完成         | 有       | 完成，总体最佳 |
| GPT5.6 Sol Medium | 11分钟   | 论文语义完整             | 6 顶点 list  | 完成         | 有       | 完成           |
