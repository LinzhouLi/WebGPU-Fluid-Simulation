Actually, I realize there's another important consideration. The Narrow Range Filter paper uses the following approach for filtering:

The "narrow range" refers to the depth range used in the bilateral filter. The filter only smooths depth values that are within a narrow range of each other. This preserves sharp edges (like the boundary between the fluid and a solid object) while smoothing the interior of the fluid surface.

The bilateral filter weight: w(xi, x) = G_s(|xi - x|) * G_r(|D(xi) - D(x)|)

Where:

G_s is the spatial Gaussian
G_r is the range Gaussian (the "narrow range" part)
D is the depth
The "narrow range" means G_r has a small sigma (narrow), so only pixels with similar depth values are averaged together.

For implementation:

Separable approximation: horizontal then vertical
Each pass is a 1D bilateral filter
Use a fixed kernel size (e.g., 5-9 pixels)
In the compute shader:


for each pixel (x, y):
  weighted_sum = 0
  weight_sum = 0
  center_depth = depth[x, y]
  for offset in [-4, 4]:
    sample_depth = depth[x + offset, y]
    spatial_weight = gaussian(offset, sigma_spatial)
    range_weight = gaussian(sample_depth - center_depth, sigma_range)
    weight = spatial_weight * range_weight
    weighted_sum += sample_depth * weight
    weight_sum += weight
  filtered_depth[x, y] = weighted_sum / weight_sum

# Narrow Range Filter Fluid Rendering Implementation Plan

## Context

The current project renders fluid particles as instanced sphere meshes with simple Lambert shading — each particle is a low-poly sphere, producing a rough, "particulate" look. The user wants to implement screen-space fluid rendering based on the Narrow Range Filter paper to produce a smooth, continuous fluid surface with physically-based reflection and refraction.

## Overview

Replace the current instanced-sphere particle renderer (`RawParticles`) with a screen-space fluid renderer that:
1. Renders particles as billboard quads (much more efficient)
2. Smooths the discrete particle depth map using a narrow-range bilateral filter
3. Renders the fluid surface in screen space with reflection (direct env map lookup) and "refraction" (env map distorted by surface normal + Fresnel blending)

## Architecture: Multi-Pass Rendering

### New Files

**`src/renderer/fluid/billboardShader.ts`** — Billboard particle shaders
- Vertex shader: per-instance quad generation. Reads particle position from storage buffer. Creates a camera-facing quad in view space offset by `±particleRadius`. Uses `@builtin(vertex_index)` (0-5 for two triangles) and `@builtin(instance_index)`.
- Fragment shader: ray-sphere intersection to compute correct sphere depth per pixel. Discards fragments outside the sphere. Optionally accumulates thickness into a separate render target.

**`src/renderer/fluid/filterShader.ts`** — Narrow-range bilateral filter compute shaders
- Horizontal pass: 1D bilateral filter with Gaussian spatial + range weights. Spatial sigma ~2px, range sigma based on `particleRadius` converted to depth units.
- Vertical pass: same logic along the other axis.
- Uses shared memory (workgroup tile + apron) for efficient texture sampling.

**`src/renderer/fluid/surfaceShader.ts`** — Screen-space surface shading
- Vertex shader: full-screen triangle (3 vertices covering clip space, no vertex buffer needed)
- Fragment shader: reconstructs view-space position from depth, computes normal via central-difference depth gradient, computes Fresnel-weighted environment map reflection, outputs to canvas.

**`src/renderer/fluid/fluid.ts`** — Fluid renderer orchestrator
- Manages intermediate textures (depth, filtered depth)
- Creates all pipelines and bind groups
- `render(commandEncoder)` method executes all passes in sequence

### Modified Files

**`src/renderer/globalResource.ts`** — Register new resource formats:
- `fluidDepth`: `texture`, `R32Float`, render attachment + texture binding + storage binding
- `fluidDepthFiltered`: same format, for the filtered output
- Point sampler (nearest-neighbor) for depth lookups
- Full-screen quad vertex buffer (or use no-buffer approach)

**`src/controller.ts`** — Replace `RawParticles` with `Fluid` renderer:
- In `initScene()`: create `Fluid` instance instead of `RawParticles`
- In `run()`: restructure the render loop to multiple passes
  - Pass 1: render skybox + mesh → canvas (store as background color texture)
  - Actually simpler: render background to a texture, then composite with fluid
  - Actually simplest for v1: render skybox + mesh first to canvas, then fluid composite reads env map directly for reflection (no background-texture dependency). Fluid pixels are blended on top.

**`src/common/config.ts`** — Add fluid rendering options (filter radius, enable/disable)

**`src/main.ts`** — No changes needed (or minimal wiring)

Actually, there's a WebGPU limitation: `r32float` with `STORAGE_BINDING` for compute write access may not be universally supported. The `bgra8unorm` format supports `STORAGE_BINDING` everywhere, but for depth we need float.

**Alternative**: Use a full-screen render pass + fragment shader for each filter pass instead of compute. This avoids the storage texture requirement. The filter reads the source texture and writes to a render target.

**Decision**: Use render passes (full-screen quads) for the filter. Simpler, more compatible.

### Filter Approach (Render-Pass Based)

Each filter pass renders a full-screen quad:
- Fragment shader samples the source depth texture in a 1D neighborhood
- Computes bilateral weights and outputs filtered depth

Pass order:
1. Billboard → fluidDepth
2. Filter H → fluidDepthFilteredH (reads fluidDepth)
3. Filter V → fluidDepthFiltered (reads fluidDepthFilteredH)
4. Background → sceneColor + sceneDepth
5. Composite → canvas (reads sceneColor, sceneDepth, fluidDepthFiltered, envMap)

### Detailed Shader Design

#### Billboard Vertex Shader

```
Input: @builtin(vertex_index) vertIdx : u32
       @builtin(instance_index) instIdx : u32
       @group(0) @binding(0) camera : Camera
       @group(1) @binding(0) particlePositions : storage array<vec3<f32>>
       @group(1) @binding(1) particleRadius : uniform f32

Output: @builtin(position) vec4<f32>
        @location(0) viewPos : vec3<f32>        // view-space particle center
        @location(1) cornerOffset : vec2<f32>   // signed corner offset (±1, ±1)

Algorithm:
1. Read particle position from storage
2. Transform to view space: p_view = camera.viewMatrix * vec4(particlePos, 1.0)
3. Generate corner offset based on vertIdx:
   - idx 0,3: (-1, -1)
   - idx 1:   ( 1, -1)
   - idx 2,4: ( 1,  1)  
   - idx 5:   (-1,  1)
4. Offset view-space xy: p_view.xy += cornerOffset * particleRadius
5. Project to clip space: p_clip = camera.projectionMatrix * p_view
6. Output: p_clip, particle_center_view_space, cornerOffset
```

#### Billboard Fragment Shader

```
Input: @location(0) viewPos : vec3<f32>         // view-space particle center
       @location(1) cornerOffset : vec2<f32>

Output: @builtin(frag_depth) f32                 // interpolated, then overridden

Algorithm:
1. Ray-sphere intersection in view space:
   - Ray from origin (0,0,0) through fragment's view-space position
   - Sphere centered at viewPos with radius particleRadius
   - Solve quadratic for t
   - If no intersection (discriminant < 0): discard
   - depth = front intersection depth
2. Compute linear depth from the intersection
3. Output via frag_depth
```

#### Filter Fragment Shader (separable, horizontal pass)

```
Input: full-screen quad UV
       @group(0) @binding(0) sourceDepth : texture_2d<f32>
       @group(0) @binding(1) pointSampler : sampler
       @group(0) @binding(2) filterParams : uniform { sigmaRange, kernelRadius, texelSize }

Output: @location(0) filteredDepth : f32
       (depth attachment: r32float for writing depth equivalent)
       Actually, since this is a render pass, we output color representing depth.

Wait — if we use a render pass, the output is a color attachment. We need to render to the filtered depth texture as a color attachment (r32float). Then in the next pass, we sample it as a texture.

Algorithm:
1. Compute center depth
2. Loop over horizontal neighbors: [-kernelRadius, kernelRadius]
3. For each neighbor:
   - spatialWeight = exp(-offset^2 / (2 * sigmaSpatial^2))
   - depthDiff = abs(neighborDepth - centerDepth)
   - rangeWeight = exp(-depthDiff^2 / (2 * sigmaRange^2))
   - weight = spatialWeight * rangeWeight
   - weightedSum += neighborDepth * weight
   - weightSum += weight
4. Output weightedSum / weightSum
5. If centerDepth >= maxDepth (no fluid): output maxDepth
```

#### Surface Shader (Composite Pass)

```
Input: full-screen UV (or compute from fragment coordinate)

Uniforms/bindings:
- camera (inverse projection, inverse view, position)
- sceneColor texture  
- sceneDepth texture
- fluidDepthFiltered texture
- envMap cube texture + sampler
- pointSampler

Output: canvas color

Algorithm:
1. Sample fluid depth at this pixel
2. If fluid depth is far plane (no fluid): output sceneColor, done
  
3. Reconstruct view-space fluid position:
   ndc = vec2(pixelCoord) / textureSize * 2.0 - 1.0
   ndc.y *= -1.0  // flip Y
   clipPos = vec4(ndc.x, ndc.y, fluidDepth, 1.0)
   viewPos4 = camera.invProjection * clipPos
   viewPos = viewPos4.xyz / viewPos4.w

4. Compute normal from depth gradient:
   Sample neighboring depths (up, down, left, right)
   Reconstruct their view-space positions
   Compute central differences
   normal = normalize(cross(dp_dx, dp_dy))

5. Compute view direction: viewDir = normalize(-viewPos)  (in view space)
   
6. Reflect view direction: reflDir = reflect(-viewDir, normal)
   Sample envMap with reflDir in world space (transform by invView)

7. Compute Fresnel (Schlick):
   f0 = 0.04 (water-like)
   fresnel = f0 + (1 - f0) * pow(1 - abs(dot(normal, viewDir)), 5)

8. Blend:
   fluidColor = fresnel * reflectionColor  (no refraction for v1, or use env map for both)

9. Output vec4(fluidColor, 1.0)
   Blend fluid color on top of sceneColor with some alpha based on Fresnel
```

fn main(@builtin(vertex_index) vertexIdx: u32) -> VertexOutput {

    vec2<f32>( 3.0, -1.0),
  );
  var uv  = array<vec2<f32>, 3>(
    vec2<f32>(0.0, 2.0),
    vec2<f32>(0.0, 0.0),
    vec2<f32>(2.0, 0.0),
  );

  let p = pos[vertexIdx];

const filterFragmentShader = /* wgsl */`
struct FragmentInput {
  @builtin(position) position: vec4<f32>,
  @location(0) uv: vec2<f32>,
};

struct FilterParams {
  texelSize: vec2<f32>,   // 1.0 / textureSize
  isHorizontal: u32,       // 1 = horizontal, 0 = vertical
  sigmaRange: f32,         // range sigma in NDC depth units
  kernelRadius: u32,       // filter kernel half-width in pixels
};

@group(0) @binding(0) var sourceDepth: texture_2d<f32>;
@group(0) @binding(1) var pointSampler: sampler;
@group(0) @binding(2) var<uniform> params: FilterParams;

@fragment
fn main(input: FragmentInput) -> @location(0) f32 {
  let centerDepth = textureSample(sourceDepth, pointSampler, input.uv).r;

  // If no fluid at this pixel (far plane / zero depth), pass through
  if (centerDepth <= 0.0001) {
    return centerDepth;
  }

  let sigmaSpatial = 2.0; // spatial sigma in pixels
  let sigmaR = params.sigmaRange;
  let kRadius = i32(params.kernelRadius);
  let twoSigmaS2 = 2.0 * sigmaSpatial * sigmaSpatial;
  let twoSigmaR2 = 2.0 * sigmaR * sigmaR;

  var weightedSum = 0.0;
  var weightSum = 0.0;

  // Sample in the filter direction
  var step = vec2<f32>(0.0, 0.0);
  if (params.isHorizontal == 1u) {
    step = vec2<f32>(params.texelSize.x, 0.0);
  } else {
    step = vec2<f32>(0.0, params.texelSize.y);
  }

  for (var i = -kRadius; i <= kRadius; i++) {
    let offset = f32(i);
    let sampleCoord = input.uv + step * offset;
    let sampleDepth = textureSampleLevel(sourceDepth, pointSampler, sampleCoord, 0.0).r;

    // Skip far-plane samples
    if (sampleDepth <= 0.0001) {
      continue;
    }

    let spatialW = exp(-offset * offset / twoSigmaS2);
    let depthDiff = abs(sampleDepth - centerDepth);
    let rangeW = exp(-depthDiff * depthDiff / twoSigmaR2);
    let w = spatialW * rangeW;

    weightedSum += sampleDepth * w;
    weightSum += w;
  }

  if (weightSum < 0.0001) {
    return centerDepth;
  }

  return weightedSum / weightSum;
}
`;

const fragmentShader = /* wgsl */`
${ShaderStruct.Camera}
${ShaderCode.GlobalGroup}

struct FragmentInput {
  @builtin(position) position: vec4<f32>,
  @location(0) uv: vec2<f32>,
};

@group(1) @binding(0) var fluidDepthTexture: texture_2d<f32>;
@group(1) @binding(1) var pointSampler: sampler;
@group(1) @binding(2) var sceneColorTexture: texture_2d<f32>;
@group(1) @binding(3) var sceneDepthTexture: texture_2d<f32>;
@group(1) @binding(4) var<uniform> surfaceParams: vec4<f32>; // xy: texel size, z: refractive index (eta), w: unused

fn linearEyeDepth(d: f32) -> f32 {
  return 1.0 / (camera.params.z * d + camera.params.w);
}

fn viewPosFromDepth(uv: vec2<f32>, depth: f32) -> vec3<f32> {
  // Reconstruct view-space position from UV and reverse-Z depth
  let clipX = uv.x * 2.0 - 1.0;
  let clipY = (1.0 - uv.y) * 2.0 - 1.0; // flip Y for NDC
  let clipPos = vec4<f32>(clipX, clipY, depth, 1.0);
  let viewPos4 = camera.projectionMatrixInverse * clipPos;
  return viewPos4.xyz / viewPos4.w;
}

fn computeNormal(viewPos: vec3<f32>, uv: vec2<f32>) -> vec3<f32> {
  let texelSize = surfaceParams.xy;
  let eps = 0.0001;

  // Sample depths at neighboring pixels
  let dU = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>( texelSize.x, 0.0), 0.0).r;
  let dD = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>(-texelSize.x, 0.0), 0.0).r;
  let dL = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>(0.0,  texelSize.y), 0.0).r;
  let dR = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>(0.0, -texelSize.y), 0.0).r;

  // Reconstruct view-space positions for neighbors
  // For pixels at the boundary (depth ~ 0), use center depth
  let dp_dx = select(
    viewPosFromDepth(uv + vec2<f32>( texelSize.x, 0.0), dU),
    viewPos,
    dU < eps
  ) - select(
    viewPosFromDepth(uv + vec2<f32>(-texelSize.x, 0.0), dD),
    viewPos,
    dD < eps
  );

  let dp_dy = select(
    viewPosFromDepth(uv + vec2<f32>(0.0,  texelSize.y), dL),
    viewPos,
    dL < eps
  ) - select(
    viewPosFromDepth(uv + vec2<f32>(0.0, -texelSize.y), dR),
    viewPos,
    dR < eps
  );

  let n = normalize(cross(dp_dx, dp_dy));

  // Face the normal toward the camera (view direction = -normalize(viewPos))
  let viewDir = normalize(viewPos); // from fragment to camera in view space
  if (dot(n, viewDir) < 0.0) {
    return -n;
  }
  return n;
}

@fragment
fn main(input: FragmentInput) -> @location(0) vec4<f32> {
  let sceneColor = textureSampleLevel(sceneColorTexture, pointSampler, input.uv, 0.0);
  let fluidDepth = textureSampleLevel(fluidDepthTexture, pointSampler, input.uv, 0.0).r;

  // If no fluid at this pixel, output the scene color directly
  if (fluidDepth < 0.0001) {
    return sceneColor;
  }

  // Check scene depth to ensure fluid is in front of scene geometry
  let sceneDepth = textureSampleLevel(sceneDepthTexture, pointSampler, input.uv, 0.0).r;
  if (sceneDepth > 0.0001 && fluidDepth < sceneDepth) {
    // Scene object is in front of fluid
    return sceneColor;
  }

  // Reconstruct view-space position of fluid surface
  let viewPos = viewPosFromDepth(input.uv, fluidDepth);

  // Compute surface normal from depth gradient
  let N_view = computeNormal(viewPos, input.uv);

  // View direction in view space (from surface to camera)
  let V = normalize(-viewPos);

  // Transform normal to world space for env map sampling
  // camera.viewMatrixInverse transforms from view to world
  let N_world = normalize((camera.viewMatrixInverse * vec4<f32>(N_view, 0.0)).xyz);
  let V_world = normalize((camera.viewMatrixInverse * vec4<f32>(V, 0.0)).xyz);

  // Reflection
  let R = reflect(-V_world, N_world);
  let reflectionColor = textureSampleLevel(envMap, linearSampler, R, 0.0).rgb;

  // Refraction (simplified: sample env map in refracted direction)
  let eta = surfaceParams.z; // refractive index, e.g. 1.33 for water
  let cosI = abs(dot(N_world, V_world));
  let sinT2 = eta * eta * (1.0 - cosI * cosI);
  var refractionColor = reflectionColor; // fallback for total internal reflection

  if (sinT2 < 1.0) {
    let cosT = sqrt(1.0 - sinT2);
    let T = normalize(eta * (-V_world) + (eta * cosI - cosT) * N_world);
    refractionColor = textureSampleLevel(envMap, linearSampler, T, 0.0).rgb;
  }

  // Fresnel (Schlick approximation)
  let f0 = 0.04; // water-air interface
  let fresnel = f0 + (1.0 - f0) * pow(1.0 - cosI, 5.0);

  // Blend reflection and refraction
  let fluidColor = mix(refractionColor, reflectionColor, vec3<f32>(fresnel));

  // Specular highlight (Blinn-Phong)
  let H = normalize(V_world + vec3<f32>(0.0, 1.0, 0.0)); // approximate light from above
  let spec = pow(max(dot(N_world, H), 0.0), 256.0) * 0.3;

  return vec4<f32>(fluidColor + spec, 1.0);
}
`;

fn viewPosFromDepth(uv: vec2<f32>, depth: f32) -> vec3<f32> {
  // Reconstruct view-space position from UV and reverse-Z depth
  let clipX = uv.x * 2.0 - 1.0;
  let clipY = (1.0 - uv.y) * 2.0 - 1.0;
  let clipPos = vec4<f32>(clipX, clipY, depth, 1.0);
  let viewPos4 = invProj * clipPos;
  return viewPos4.xyz / viewPos4.w;
}

fn computeNormal(viewPos: vec3<f32>, uv: vec2<f32>) -> vec3<f32> {
  let texelSize = surfaceParams.xy;

  // Sample depths at neighboring pixels
  let dU = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>( texelSize.x, 0.0), 0.0).r;
  let dD = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>(-texelSize.x, 0.0), 0.0).r;
  let dL = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>(0.0,  texelSize.y), 0.0).r;
  let dR = textureSampleLevel(fluidDepthTexture, pointSampler, uv + vec2<f32>(0.0, -texelSize.y), 0.0).r;

  // For boundary pixels, fall back to center position
  let eps = 0.0001;
  let posR = select(viewPosFromDepth(uv + vec2<f32>( texelSize.x, 0.0), dU), viewPos, dU < eps);
  let posL = select(viewPosFromDepth(uv + vec2<f32>(-texelSize.x, 0.0), dD), viewPos, dD < eps);
  let posU = select(viewPosFromDepth(uv + vec2<f32>(0.0,  texelSize.y), dL), viewPos, dL < eps);
  let posD = select(viewPosFromDepth(uv + vec2<f32>(0.0, -texelSize.y), dR), viewPos, dR < eps);

  let dp_dx = posR - posL;
  let dp_dy = posU - posD;

  let n = normalize(cross(dp_dx, dp_dy));

  // Ensure normal faces the camera
  let viewDir = normalize(viewPos);
  return select(n, -n, dot(n, viewDir) < 0.0);
}

@fragment
fn main(input: FragmentInput) -> @location(0) vec4<f32> {
  let sceneColor = textureSampleLevel(sceneColorTexture, pointSampler, input.uv, 0.0);
  let fluidDepth = textureSampleLevel(fluidDepthTexture, pointSampler, input.uv, 0.0).r;

  // No fluid at this pixel
  if (fluidDepth < 0.0001) {
    return sceneColor;
  }

  // Scene object in front of fluid
  let sceneDepth = textureSampleLevel(sceneDepthTexture, pointSampler, input.uv, 0.0).r;
  if (sceneDepth > 0.0001 && fluidDepth < sceneDepth) {
    return sceneColor;
  }

  // Reconstruct view-space position
  let viewPos = viewPosFromDepth(input.uv, fluidDepth);

  // Compute normal from depth gradient
  let N_view = computeNormal(viewPos, input.uv);

  // View direction in view space
  let V = normalize(-viewPos);

  // Transform to world space for env map sampling
  let N_world = normalize((camera.viewMatrixInverse * vec4<f32>(N_view, 0.0)).xyz);
  let V_world = normalize((camera.viewMatrixInverse * vec4<f32>(V, 0.0)).xyz);

  // Fresnel (Schlick)
  let f0 = 0.04;
  let cosI = abs(dot(N_world, V_world));
  let fresnel = f0 + (1.0 - f0) * pow(1.0 - cosI, 5.0);

  // Reflection
  let R = reflect(-V_world, N_world);
  let reflectionColor = textureSampleLevel(envMap, linearSampler, R, 0.0).rgb;

  // Refraction (env map as approximation of background)
  let eta = surfaceParams.z; // n1/n2 ≈ 0.752 for air→water
  let sinT2 = eta * eta * (1.0 - cosI * cosI);
  var fluidColor = reflectionColor;

  if (sinT2 < 1.0) {
    let cosT = sqrt(1.0 - sinT2);
    let T = normalize(eta * (-V_world) + (eta * cosI - cosT) * N_world);
    let refractionColor = textureSampleLevel(envMap, linearSampler, T, 0.0).rgb;
    fluidColor = mix(refractionColor, reflectionColor, vec3<f32>(fresnel));
  }

  // Specular highlight from light direction
  let lightDir = normalize(light.direction);
  let H = normalize(V_world + lightDir);
  let spec = pow(max(dot(N_world, H), 0.0), 256.0) * 0.3 * light.color;

  return vec4<f32>(fluidColor + spec, 1.0);
}

  public async runTimestamp() {

    frame++;
    const commandEncoder = device.createCommandEncoder();
    commandEncoder.writeTimestamp(timeStampQuerySet, 0);

    // simulation
    for (let i = 0; i < this.simulator.stepCount; i++)
      this.simulator.runTimestamp(commandEncoder);

    // Scene pass
    const scenePass = this.fluidRenderer.beginScenePass(commandEncoder);
    this.globalResource.setResource(scenePass);
    if (this.ifMesh) this.mesh.render(scenePass);
    if (this.ifSkybox) this.skybox.render(scenePass);
    scenePass.end();

    if (this.ifParticles && this.simulator.particleCount > 0) {
      // Billboard pass
      const billboardPass = this.fluidRenderer.beginBillboardPass(commandEncoder);
      this.globalResource.setResource(billboardPass);
      this.fluidRenderer.renderBillboards(billboardPass);
      billboardPass.end();

      // Filter passes
      const filterHPass = this.fluidRenderer.beginFilterHPass(commandEncoder);
      this.fluidRenderer.renderFilterH(filterHPass);
      filterHPass.end();

      const filterVPass = this.fluidRenderer.beginFilterVPass(commandEncoder);
      this.fluidRenderer.renderFilterV(filterVPass);
      filterVPass.end();

      // Surface composite
      const ctxTextureView = this.context.getCurrentTexture().createView();
      const surfacePass = commandEncoder.beginRenderPass({
        colorAttachments: [{
          view: ctxTextureView,
          clearValue: { r: 0, g: 0, b: 0, a: 1.0 },
          loadOp: 'clear',
          storeOp: 'store',
        }],
      });
      this.globalResource.setResource(surfacePass);
      this.fluidRenderer.renderSurface(surfacePass);
      surfacePass.end();
    } else {
      const ctxTextureView = this.context.getCurrentTexture().createView();
      const copyPass = commandEncoder.beginRenderPass({
        colorAttachments: [{
          view: ctxTextureView,
          clearValue: { r: 0, g: 0, b: 0, a: 1.0 },
          loadOp: 'clear',
          storeOp: 'store',
        }],
      });
      this.globalResource.setResource(copyPass);
      if (this.ifSkybox) this.skybox.render(copyPass);
      if (this.ifMesh) this.mesh.render(copyPass);
      copyPass.end();
    }

    commandEncoder.writeTimestamp(timeStampQuerySet, 5);

    commandEncoder.resolveQuerySet(
      timeStampQuerySet, 0, this.timeStampSize,
      this.timeStampBuffer, 0
    );
    commandEncoder.copyBufferToBuffer(
      this.timeStampBuffer, 0,
      this.timeStampReadBuffer, 0,
      this.timeStampBuffer.size
    );

    const commandBuffer = commandEncoder.finish();
    device.queue.submit([commandBuffer]);

    await device.queue.onSubmittedWorkDone();
    await this.timeStampReadBuffer.mapAsync(GPUMapMode.READ);
    const buffer = this.timeStampReadBuffer.getMappedRange(0, this.timeStampReadBuffer.size);
    const array = new BigUint64Array(buffer);
    for (let i = 1; i < this.timeStampSize; i++) {
      this.timeStampReadArray[i-1] += Number(array[i] - array[i-1]) * 1e-3;
    }
    this.timeStampReadBuffer.unmap()

    if (frame == 300) {
      this.timeStampReadArray.forEach(val => console.log(val / frame));
    }

  }

    this.simulator.update();

    // Update inverse projection for fluid surface shader
    const invProj = this.camera.projectionMatrixInverse.toArray();

  }
